# 🤖 Telegram Bot (Python + Telebot)

A simple Telegram bot built using **Python** and the **PyTelegramBotAPI** (`telebot`) library. This project serves as a basic template for creating bots that respond to user commands and send messages through the Telegram Bot API.

---

## 🚀 Features

- `/start` — welcome message
- `/help` — list of available commands
- `/about` — short bot description
- Handles user messages
- Easily extendable with new commands or logic

---

## 🛠️ Tech Stack

- **Language**: Python 3
- **Library**: [PyTelegramBotAPI](https://github.com/eternnoir/pyTelegramBotAPI)
- **Platform**: Telegram
